# 运行说明

## 1. 环境准备

运行本项目需要：

- Windows 电脑
- Python 3
- 浏览器

建议直接复制整个项目目录，而不是只复制源码。因为数据库、文件库、解析归档和 PDF 导出都在项目目录内。

## 2. 安装依赖

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
```

或双击：

- `安装依赖.bat`

## 3. 启动方式

### 双击启动

- `启动程序.bat`

### 命令行启动

```powershell
python run.py
```

## 4. 当前默认启动配置

默认配置写在：

- `local_settings.json`

当前关键默认值：

- `HOST = 0.0.0.0`
- `PORT = 5050`
- `LAN_ACCESS_HOST = 192.168.1.2`
- `ADMIN_PASSWORD = 123456`
- `MAX_CONTENT_LENGTH_MB = 50`

## 5. 浏览器访问地址

启动成功后：

- 本机访问：`http://127.0.0.1:5050`
- 局域网访问：`http://192.168.1.2:5050`

手机测试时，请确认手机和电脑在同一 Wi‑Fi / 同一局域网。

## 6. 管理密码使用方式

普通浏览不需要密码。  
以下操作需要先验证管理密码：

- 上传文件
- 撤回文件
- 删除文件
- 激活文件

默认管理密码是：

- `123456`

如果要修改，可直接编辑：

- `local_settings.json`

或设置环境变量：

- `ADMIN_PASSWORD`

## 7. 上传底稿的方法

1. 打开 `http://127.0.0.1:5050` 或 `http://192.168.1.2:5050`
2. 点击“上传文件”
3. 如果当前未验证，会先进入管理验证页
4. 输入管理密码
5. 返回上传页后选择底稿文件
6. 点击“开始上传并自动处理”

支持格式：

- `.docx`
- `.md`
- `.txt`
- `.pdf`

## 8. 上传简报的方法

和底稿上传方式相同。  
系统会根据文件名和内容自动识别它是研究底稿还是每日简报。

## 9. 导出 PDF 的方法

导出入口在：

- 首页顶部
- 板块详情页顶部
- 历史记录页

点击后系统会生成当日 PDF，并保存到：

- `exports/pdf/`

## 12. 常见报错与排查

### 1. 无法上传文件

先检查：

- 是否已完成管理验证
- 文件格式是否在白名单内
- 文件是否超过 `50MB`

### 2. 手机打不开局域网地址

先检查：

- 电脑和手机是否在同一 Wi‑Fi
- 程序是否已启动
- `http://192.168.1.2:5050` 是否拼写正确
- Windows 防火墙是否拦截 Python 或 5050 端口

### 3. 页面显示正常，但无法管理文件

说明当前只是浏览态。  
先点击“管理验证”，输入管理密码后再操作。

### 4. 上传后页面没有刷新到新内容

先检查：

- 上传结果区是否提示成功
- 文件日期是否识别正确
- 文件库中该文件是否为“当前生效”

### 5. 适不适合直接公网部署

当前还不适合直接裸奔上公网。  
还缺少：

- 完整账号体系
- 角色权限
- HTTPS
- 更强的服务端安全加固
- 更适合公网的数据库与部署结构

## 13. 新增的底稿验证规则

当前上传研究底稿时，系统会先做结构验证，再决定是否入库。重点检查：

- 主标题是否为《沉香行业情报研究底稿》
- 是否包含 10 个固定一级板块
- 模块 1 是否包含 `1.1 数据与规则`、`1.2 编制原则`
- 模块 2–10 是否包含 `x.1 / x.2 / x.3 / x.4`
- 结构化表格是否严格为 6 列：
  `标题 / 时间 / 来源层级 / 来源 / 核心内容 / 为什么值得纳入`
- 是否混入无法归类的自由段落
- 是否带有 AI 尾巴或非正文提示语

验证失败时，上传页会直接显示具体错误项，例如：

- 哪个模块缺少固定小节
- 哪张表格列数不对
- 哪段自由文本无法归类
- 是否检测到需要删除的尾巴内容

完整模板规范见：

- `DRAFT_TEMPLATE_SPEC.md`

## 14. 当前展示逻辑说明

当前版本不再只是展示“最后一次上传的单个文件快照”，而是：

- 原始文件继续逐份归档
- 展示层改成“截至当前日期的累计有效内容视图”
- 较早日期的有效条目，如果在新版本里没有被替换，会继续在首页、板块页和 PDF 中显示
- “新增 / 更新 / 历史保留”现在只用于状态标注，不再决定旧内容是否消失
