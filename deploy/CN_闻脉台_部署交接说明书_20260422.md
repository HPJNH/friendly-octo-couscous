# 闻脉台部署交接说明书

## 1. 项目概览
- 项目名称：闻脉台
- 当前用途：面向沉香行业情报的上传、解析、阅读、版本追踪与管理
- 当前阶段：封箱前的部署交接整理阶段
- 当前部署目标：优先完成第三方环境下的单实例试跑、启动验证与目录挂载验证，不以正式公网放量为目标

## 2. 可交付范围
本说明书面向“仅负责部署和试跑”的第三方部署方。可交付内容仅限：

- 程序本体代码
- 配置模板
- 当前有效部署说明
- 当前有效规范文档
- 测试脚本

以下内容不在第三方部署交付范围内：

- 真实 `config/local_settings.json`
- 当前真实 SQLite 数据库与数据库备份
- 任何访问码恢复文件、真实日志、真实导出 PDF、真实报告
- 真实底稿、linked 底稿、review / verification 数据
- 含敏感数据的完整代码审阅包
- 任何包含真实 SECRET、真实访问码、真实账号信息的材料

## 3. 技术栈
- Python
- Flask
- Jinja 模板
- SQLite
- WSGI 服务入口：`wsgi.py`
- 当前不是 MySQL / Redis / 对象存储架构

## 4. 推荐交付的程序本体目录
第三方部署方建议只接收以下程序本体内容：

- `app/`
- `config/local_settings.example.json`
- `deploy/`
- `docs/specs/`
- `docs/RUN_GUIDE.md`
- `scripts/`
- `tests/`
- `run.py`
- `wsgi.py`
- `requirements.txt`
- `README.md`
- `.gitignore`
- `启动程序.bat`
- `安装依赖.bat`

说明：
- `run.py` 仅保留为本地入口
- 第三方服务器运行统一使用 `wsgi:app`

## 5. 启动方式
### 本地入口
- 文件：`run.py`
- 作用：本地开发、自测、本机浏览器启动

### 服务器入口
- 文件：`wsgi.py`
- 推荐方式：单实例 WSGI 启动
- 推荐入口：`wsgi:app`

示例命令：

```powershell
waitress-serve --listen=0.0.0.0:5050 wsgi:app
```

## 6. 运行目录说明
当前程序采用“代码目录”和“运行数据目录”分离的思路，第三方部署前应理解以下路径语义：

- `DATA_ROOT`：运行数据根目录
- `STORAGE_ROOT`：文件库存储、上传缓存、日志等目录根
- `EXPORTS_ROOT`：导出物目录根
- `ARCHIVE_ROOT`：运行期归档目录
- `LOG_ROOT`：日志目录

默认情况下，这些路径可以回落到项目目录内；部署时建议通过配置或环境变量统一挂到持久卷。

### 需要持久化的目录
- `DATA_ROOT`
- `STORAGE_ROOT`
- `EXPORTS_ROOT`
- `ARCHIVE_ROOT`
- `LOG_ROOT`

### 不建议与代码混放的内容
- 真实数据库
- 真实上传底稿
- 真实 linked 底稿
- 真实日志
- 真实 PDF / 报告导出物

- `APP_RUNTIME_ROOT`
- `DATA_ROOT`
- `STORAGE_ROOT`

- `ARCHIVE_ROOT`
- `LOG_ROOT`

## 8. 当前架构边界
第三方部署方必须明确接受以下边界：

- 当前默认数据库是 SQLite
- 当前只支持单实例
- 当前不适合多 worker 并发写入
- 当前不适合多实例横向扩展
- 当前未接入 MySQL / Redis / 对象存储
- 当前目标是部署试跑和运行验证，不是架构升级

建议：
- 先使用脱敏数据或测试数据试跑
- 先验证启动、路径、持久卷、导出和访问控制
- 不要在首次部署时直接导入真实敏感数据

## 9. 第三方部署注意事项
- 不要擅自改 `parser`、`rebuild`、`routes`、`db` 主逻辑
- 不要改当前上传契约、豆包模板和阅读层规则
- 不要擅自改变路径结构
- 不要把本地私密材料打进交付包
- 不要直接把当前项目目录里的运行期敏感数据复制到第三方环境
- 当前建议先做“干净代码 + 模板配置 + 脱敏样例”的部署试跑

## 12. 当前交接目标
当前项目已经整理到适合第三方执行“仅部署、仅试跑、仅验证”的状态。

但第三方部署方不应默认认为当前版本已经完成：

- 正式公网发布
- 高并发生产化
- 多实例扩容
- MySQL / Redis 云化
- 对象存储改造

当前正确目标只有一个：在不接触本地私密数据的前提下，完成可控的单实例部署试跑。
